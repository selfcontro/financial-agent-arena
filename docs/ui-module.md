# 第三模块：题目与模型回答展示

## 已实现

- Vite + React 本地页面：左侧五道题切换、题目截止时间、风险标签、可展开参考答案、关键数字及完整证据。
- 模型动态并列卡片，较多模型时横向滚动；移动端单列显示。缺失回答提供占位卡片。
- 按模型显示名称新增本地模拟模型，自动生成各题的空回答栏。
- 添加和编辑回答，编辑生成新版本；引用可从本题证据选择，也可手动填写来源、标题、发布时间及摘录。
- 缺失引用、无法匹配证据、引用晚于截止时间或回答生成时间时，提供人工核查提示，不自动评分。
- 回答软删除需确认，保留关联评审；历史弹窗展示回答版本、引用快照、删除时间和已有评分。
- 保存成功后提示；未保存回答关闭弹窗时确认，刷新前使用浏览器离开提示；服务错误保留输入并显示原因。

## 启动

```sh
npm ci
npm run dev
```

访问终端输出的本地 URL，默认 `http://127.0.0.1:5173`。若端口被占用，以终端实际输出为准。不同主机名/端口属于不同浏览器存储空间。

```sh
npm test
npm run build
```

## 浏览器验证记录

2026-09-19，使用 Codex 内置浏览器在本地开发服务器实际验证：

1. 五题切换，四模型初始卡片及参考证据展开。
2. 数据时效题显示未来数据和无效引用提示。
3. 新增“浏览器验收模型”，新增回答并从本题证据添加引用。
4. 页面重新加载后回答和引用保留。
5. 修改回答生成 v2；历史弹窗同时保留 v1 和 v2。
6. 软删除 v2 后显示缺失回答占位；历史仍显示 v2 的内容及删除时间。
7. 桌面横向对比与 390px 移动端单列布局，控制台未发现错误或警告。

浏览器验收创建的模型和回答仅在该浏览器的本地状态中，未写入内置种子文件。自动化服务测试另外覆盖重复回答拒绝、删除后重新添加的版本关联和写入失败回滚。

## 边界

人工评分表单、总分与排名、筛选、完整审计时间线、备份恢复界面及文件导入导出仍待后续模块。模型新增当前只录入显示名称；base_url、API Key、model_name 的连接配置界面尚未实现，不调用真实模型。

页面时间统一显示为北京时间，模拟题截止时间明确采用 `+08:00`，避免 UTC 跨日造成题意与页面日期不一致。已有本地快照保持原值，不静默修改用户数据。
