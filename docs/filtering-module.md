# 第六模块：分级筛选与单题对比

## 使用方式

侧栏打开“分级筛选”，先选择某个模型或全部模型。后续条件可以留空，依次按失败标签、评审状态和题目缩小范围。

- 多个标签默认命中任一，可切换为同时包含全部。没有选择标签时不限制标签。
- 更换模型清空标签、状态和题目；更改标签或匹配方式清空状态和题目；更改状态清空题目。
- 标签计数基于模型范围，状态计数基于模型与标签范围，题目计数基于前三层范围。零计数仍可选择，并显示空结果提示。
- 包含未评审、评审中、已完成、待补评、缺少回答、题目已更新六种展示状态；后三项属于视图状态，不改写历史人工评审状态。
- 显示当前回答版本、失败标签、评语和有效总分。缺少回答仍可按模型和题目定位；旧版或已删除回答的标签不匹配当前记录。
- 筛选可以定位评审中的失败标签，正式统计仍只接受有效完成记录，两者用途不同。
- 每行“查看同题全部模型”回到该题完整比较页面，不隐藏其他模型；重新打开筛选页保留条件。
- 筛选仅为页面状态，刷新后重置，不改变排行榜、评审、审计或备份。

## 实现与验证

`src/services/filtering.ts` 使用统一汇总服务提供的当前回答与评审关系，依次生成候选记录及上级范围计数。`src/components/ReviewExplorer.tsx` 提供控件和结果表，筛选状态由 App 保留。

新增 4 个测试覆盖模型范围、缺少回答、标签任一与全部匹配、状态和题目组合、上级计数、零分、旧版本标签隔离、待补评、切换模型重置、同题跳转及重置按钮。

2026-09-19：`npm test` 共 7 个文件、57 个测试通过；`npm run build` 通过。浏览器使用已有测试评分验证两个标签同时匹配得到 1 条结果，跳转后显示同题 5 个模型；切换到豆包清空下级条件并恢复 5 条记录。390px 窄屏页面无横向溢出，结果表内部滚动。未增加或修改正式人工评分。
