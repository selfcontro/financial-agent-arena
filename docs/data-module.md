# 第一模块：数据与校验

## 数据范围

提供营收同比、单位换算、数据时效、风险识别、因果判断五道题，每题包含四条不同质量的模拟回答。公司和证据均为虚构资料，正文在 JSON 内保存，不依赖网络来源。

`allowed_evidence` 的第三题包含截止日后修订公告作为核查对照，该证据明确注明不可用于截止时点结论；人工需结合 `published_at` 和 `cutoff_at` 判断是否可用。

## 数据关联

- 题目由 `case_id + version` 标识。
- 回答由 `answer_id + version` 标识，并绑定题目版本和模型。
- 每个题目与模型最多有一个有效当前回答。
- 评审绑定回答版本及 `scoring_version`，对应题目和模型必须一致。
- 同一回答版本最多有一条评审记录，其修改前后快照未来由审计服务保存。
- 当前规则与历史规则使用不同版本号。旧评审完成性按其关联规则校验；新增维度后的待补评提示留给后续统计模块。

## 人工错误与结构错误

不存在的引用和截止日后数据是刻意设置的错误样本，不属于校验失败。评审绑定不存在的回答版本、重复维度、非法分数和错误权重则会被拒绝。

失败标签包括数字错误、单位错误、引用无效、使用未来数据、风险漏报、无依据买卖建议、因果关系表述不当。题目的 `risk_labels` 提示核查场景，不自动给模型回答打标签或评分。

## 密钥

连接配置类型包含 `base_url`、`api_key`、`model_name`，但它与可移植数据集分离；模型定义可以携带非敏感连接信息。可移植数据结构不接受密钥字段，审计快照也拒绝嵌套 API Key 字段。实际连接设置和导出脱敏功能尚未实现。本模块的字段检查不能识别自由文本中任意格式的秘密。

## 尚未实现

此模块只提供数据和校验函数；不包含存储写入、历史变更服务、接口调用、UI、排名算法、报告、备份或导入交互。Schema 目前面向全部标记为模拟的第一版数据；未来真实数据支持需要单独扩展。
