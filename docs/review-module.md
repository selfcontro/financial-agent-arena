# 第四模块：人工评审表单

## 已实现

每个当前回答提供“开始评审 / 编辑评审”。弹窗根据启用维度动态生成评分项，以数组保存 `dimension_id`、分数和名称快照，绑定回答版本。

- 0～10 整数评分；0 是有效分数，空白不补 0。
- 部分分数可保存为评审中；已完成必须填写所有启用维度，包括权重为 0 的维度。
- 七类失败标签多选，允许没有失败标签；评语可为空。
- 未评审、评审中、已完成三种状态。首次填写时自动切换评审中，也可手动选择状态。
- 保存后卡片展示原始分数、标签、评语和最近保存时间；刷新后恢复，已完成记录仍可修改。
- 恢复已保存内容只重置表单草稿，不清除正式记录；关闭未保存表单时确认放弃，页面刷新提供浏览器离开提示。
- 保存错误保持用户输入，不关闭表单；数据与审计一起保存。
- 修改历史显示每次创建或修改的时间、状态、分数、标签和评语前后快照。
- 旧完成记录在当前配置缺少维度时显示“待补评”，历史状态不变。补齐后可重新保存。

## 测试

React Testing Library + jsdom 组件测试覆盖动态维度、0 分与空白、部分保存、多标签、完成校验、分数边界、编辑与恢复、关闭保护、保存失败保留输入、新维度补评。存储测试继续验证刷新恢复及版本绑定。

浏览器实际验收（2026-09-19）：

1. 在“浏览器验收模型”上录入零分和测试评语，保存为评审中，重新加载后保留。
2. 缺少维度时选择已完成，保存被阻止并提示具体缺失维度。
3. 补齐后保存已完成，再修改原分数和失败标签，卡片即时更新。
4. 展开历史，检查创建、部分到完成、完成后修改三个事件的前后快照。
5. 390px 移动端弹窗可滚动，控件无横向溢出；浏览器控制台未发现警告或错误。

浏览器自动验收评分在评语中标明测试用途，不属于正式人工评审；内置种子数据的 reviews 仍为空。
