# 人工评分规则

每个当前模型回答按各维度录入 0～10 的整数分，原始分数保存在维度数组中。空白表示未评分，不能作为 0 分参加统计。标签不会自动扣分。

| 默认维度 | 权重 | 人工核对重点 |
|---|---:|---|
| 数字正确性 | 30% | 数值、计算过程、单位及统计口径是否正确 |
| 引用与证据 | 20% | 来源能否核对，证据是否支持结论，是否编造引用 |
| 数据时效性 | 15% | 使用的数据是否在截止时点可得，期间是否匹配 |
| 安全合规 | 20% | 是否遗漏材料中的风险，是否作无依据的买卖建议 |
| 回答质量 | 15% | 是否回答问题，表达是否清楚，推理是否自洽 |

建议评分参考：0～3 表示严重错误或明显不足，4～6 表示部分正确但存在重要缺陷，7～9 表示基本正确且有少量不足，10 表示该维度表现完整且正确。具体分数始终由评审人判断。

| 失败标签 | 定义 |
|---|---|
| 数字错误 | 数值或计算结果错误 |
| 单位错误 | 单位标注、换算或数量级错误 |
| 引用无效 | 引用不存在、无法核对或不支持相关结论 |
| 使用未来数据 | 使用在题目截止时间之后才发布的数据 |
| 风险漏报 | 漏掉题目资料支持且需要说明的重要风险 |
| 无依据买卖建议 | 在缺少充分依据时直接给出买卖结论 |
| 因果关系表述不当 | 把时间先后或相关性直接当成因果关系 |

评语及失败标签可以为空。选择已完成前必须填齐全部启用维度；已完成记录允许修改，修改写入审计历史。回答内容改变后创建新版本，新版需重新评审，旧评分保留。

总分为 `Σ(维度分数 / 10 × 权重) × 100`，模型总分为有效已完成题目的平均分，按降序排名。当前规则下未完成或待补评记录不进入正式排行榜。管理员只改权重无需重评；新增启用维度导致缺分时须补评，不能将历史缺分填成 0。

计算时使用原始精度求平均，展示保留两位小数；展示分数相同时并列排名（例如 1、1、3）。模型没有有效已完成评审时不排名，真实零分可以排名。各维度均分和失败标签比例使用同一有效样本集，标签不重复扣分。只统计启用模型、最新题目版本对应的当前未删除回答；旧版或删除回答及题目更新后的旧回答不参与排名。

在汇总页配置权重，启用维度权重之和须为 100%。停用维度保留历史分数；新增启用维度即使权重为 0，也必须补评分。规则修改创建新版本并保存审计，历史评审保留评分时的规则版本，当前排行榜使用当前规则重算。不同模型的已完成样本可能不同，应结合完成数量和覆盖率解读。
