# 第五模块：评分计算与汇总排行榜

## 已实现

- `src/services/aggregation.ts` 提供统一计算，汇总页与回答卡片使用相同公式。
- 总分满分 100，模型平均总分仅使用有效已完成的当前回答评审；缺分、未完成、待补评、旧版、已删除和过期题目回答排除。
- 正式排名、完成数量及比例、动态维度均分、七类失败标签数量和比例。
- 临时进度独立展示，模型可展开全部题目状态，点击查看单题返回并列评审。
- 权重管理支持名称、权重、启停、新增维度及恢复默认。校验启用权重合计 100%，保存配置版本与审计；原始评分不改写。
- 新增维度后历史完成记录缺分时显示待补评；补齐后恢复排名。规则调整及数据均持久化。
- 表格支持窄屏内部横向滚动。当前使用 React 状态切换页面、普通 CSS 绘制分数条，无新增路由或图表依赖。

## 验证

`npm test`：6 个测试文件、53 个测试通过。新增 9 个测试覆盖已知手算总分、维度均分、标签比例、0 分和缺分、旧版与软删除、题目版本、停用模型、改权重与新增维度、并列排名及配置校验。`npm run build` 通过。

2026-09-19 浏览器验收：

1. 已有浏览器测试模型评分为 5、6、7、8、9，默认权重总分 67.00；其他未完成模型无正式排名。
2. 将首维度权重改为 50%，合计超过 100% 时阻止保存；第二维度改为 0% 后保存，总分变为 65.00。
3. 重新加载后规则及 65.00 保留；恢复默认后总分回到 67.00，保留两次规则变更审计。
4. 模型进度中的查看单题能返回对应问题。390px 视口页面宽度仍为 390px，表格内部滚动。

浏览器评分明确标记为测试用途，不作为正式人工评审。种子数据仍然没有预填人工评分。
