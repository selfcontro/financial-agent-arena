# 金融 Agent 模型评测竞技场

当前已实现数据模块及本地存储服务：模拟数据、校验、评审保存修改、回答版本、审计、多次备份和指定恢复。现已接入题目与模型回答展示页面；人工评审表单已实现；评分统计、排行榜和权重设置已实现；报告生成、快照下载与复算校验已实现。

## 运行本模块

开发验证环境为 Node.js 22.22.1、npm 10.9.4。

```sh
npm ci
npm run dev
npm test
npm run build
```

安装依赖需要网络；模拟数据校验与测试不调用模型或外部金融数据接口。启动后访问终端显示的本地 URL（默认 http://127.0.0.1:5173）。页面支持题目切换、参考证据、并列回答和回答管理。

## 评分规则

默认五个维度为数字正确性、引用与证据、数据时效性、安全合规、回答质量；权重依次为 30%、20%、15%、20%、15%。维度分数为 0～10 的整数，通过数组保存。

总分为 `Σ(分数 / 10 × 权重) × 100`，只统计当前有效回答且完成当前维度评分的记录。模型排名按有效已完成题目的平均总分降序排列，同时显示完成率；同分并列。

## 提交状态

内置题目、证据和模型回答均为模拟，不代表问财、豆包、千问、元宝的真实表现。正式人工评审初始为空。测试夹具中的评分只用于测试。

当前 63 个测试覆盖评审保存恢复、修改及 GOAL.md 要求的汇总统计。已在浏览器验证回答保存、刷新恢复、版本历史及软删除；人工评分表单已在浏览器验证部分保存、完成校验和修改历史。完整 Agent 对话导出及最终人工评分尚未交付；程序生成的未评分四模型报告已保存于 reports/。

## 可选模型 API

已支持 Base URL、API Key、Model Name 配置和真实 HTTP 调用入口，见 [配置说明](docs/model-api.md)。默认模拟评测仍可离线运行；只有点击“发送请求”才访问供应商。密钥仅保存在本地服务内存中。生产本地运行使用 `npm run build` 后执行 `npm start`，静态 preview 不提供 API。

## 人工评审

点击模型卡片上的“开始评审 / 编辑评审”，按动态维度打分、勾选失败标签、填写评语并保存。评分为 0～10 的整数，完成前需填齐全部启用维度。详见 [模块说明](docs/review-module.md) 和 [评分规则](docs/scoring-rules.md)。

## 评分汇总与排行榜

点击侧栏“评测汇总与排行榜”，查看总分、各维度均分、失败标签分布及临时进度。展开模型进度可跳转单题。点击“评分规则与权重”调整权重、启停或增加维度；设置保存后留下版本与审计记录。无账号体系，本地使用者均可操作该管理入口。详见 [第五模块说明](docs/summary-module.md)。

## 分级筛选

侧栏“分级筛选”按模型 → 失败标签 → 评审状态 → 题目逐级缩小范围。可以选择全部模型、任一或全部标签匹配，查看当前回答版本、评语和有效总分，并跳转同题全部模型对比。切换页面保留筛选，刷新页面重置筛选；不会修改评审数据或排行榜范围。详见 [第六模块说明](docs/filtering-module.md)。

## JSON 与多备份

点击“数据与备份”导出当前完整 JSON、创建备份或下载指定备份的数据。选择 JSON 文件后先校验和预览，再点击“备份并确认完整替换”。恢复时选择历史备份并确认，系统先备份当前数据。备份保存在同一浏览器中，建议下载留存。文件包含数据及审计历史，不包含 API Key。详见 [第七模块说明](docs/transfer-module.md)。

## 程序生成对比报告

汇总页点击“生成对比报告”，可预览并下载 Markdown、完整 JSON 报告和可导入的数据快照。生成后快照固定，不随后续修改变化。

```sh
npm run report
npm run report -- path/to/exported-dataset.json reports/my-run
npm run report -- --verify reports/report.json
```

默认读取内置数据，生成 `reports/report.md` 和 `reports/report.json`。传入数据集 JSON 可生成真实已保存人工评审的报告。验证命令重新计算数据摘要、统计和 Markdown，发现不一致时失败。重复生成到同一输出目录会覆盖该目录的两个报告文件，建议每次使用独立目录。

仓库内 [四模型报告](reports/report.md) 包含 5 道题和 20 条模拟回答；内置人工评审为空，因此没有正式排名。它是未评分的程序生成报告，完成正式人工评审后应重新导出生成最终评分报告。报告计算版本与复现说明见 [第八模块](docs/report-module.md)。
