# 金融 Agent 模型评测竞技场

当前已实现第一模块：TypeScript 数据类型、模拟数据及 Zod 结构与关联校验。尚未实现页面、本地持久化、备份恢复、评分统计或正式报告。

## 运行本模块

开发验证环境为 Node.js 22.22.1、npm 10.9.4。

```sh
npm ci
npm test
npm run typecheck
```

安装依赖需要网络；模拟数据校验与测试不调用模型或外部金融数据接口。当前没有 `dev` 页面启动命令，后续界面模块再添加。

## 文件

- `src/data/dataset.json`：5 道题、4 个模型、20 条模拟回答、本地证据、默认规则和空评审列表。
- `src/data/seed.ts`：生成独立且经过校验的数据副本。
- `src/types/evaluation.ts`：由校验 Schema 推导的数据类型。
- `src/services/validation.ts`：数据结构、ID、版本关系、评分范围及权重校验。
- `tests/data.test.ts`：数据完整性、关联错误、历史规则、密钥排除和 JSON 往返测试。
- `docs/data-module.md`：数据约定和已知限制。
- `docs/validation-module-01.txt`：本模块实际验证输出。

## 评分规则

默认五个维度为数字正确性、引用与证据、数据时效性、安全合规、回答质量；权重依次为 30%、20%、15%、20%、15%。维度分数为 0～10 的整数，通过数组保存。

规划中的总分为 `Σ(分数 / 10 × 权重) × 100`，只统计当前有效回答且完成当前维度评分的记录。此模块仅校验数据，尚不计算排名。

## 提交状态

全部题目、证据和模型回答均为模拟，不代表问财、豆包、千问、元宝的真实表现。正式人工评审初始为空。测试夹具中的评分只用于测试。

当前 8 项数据测试不替代 GOAL.md 要求的评审保存、修改和汇总统计测试；这些将在对应模块实现后补齐。完整 Agent 对话导出、最终人工评分及程序生成报告也尚未交付。
