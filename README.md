# 金融 Agent 模型评测竞技场

当前已实现数据模块及本地存储服务：模拟数据、校验、评审保存修改、回答版本、审计、多次备份和指定恢复。现已接入题目与模型回答展示页面；人工评审表单已实现；评分统计和正式报告尚未实现。

## 运行本模块

开发验证环境为 Node.js 22.22.1、npm 10.9.4。

```sh
npm ci
npm run dev
npm test
npm run build
```

安装依赖需要网络；模拟数据校验与测试不调用模型或外部金融数据接口。启动后访问终端显示的本地 URL（默认 http://127.0.0.1:5173）。页面支持题目切换、参考证据、并列回答和回答管理。

## 文件

- `src/App.tsx`：题目与回答对比页面、回答编辑及历史弹窗。

- `src/data/dataset.json`：5 道题、4 个模型、20 条模拟回答、本地证据、默认规则和空评审列表。

- `src/store/`：统一持久化适配器和框架无关状态服务。
- `tests/storage.test.ts`：保存恢复、修改审计、多次备份、恢复和失败保护测试。
- `docs/storage-module.md`：状态服务调用方式和已知限制。
- `tests/data.test.ts`：数据完整性、关联错误、历史规则、密钥排除和 JSON 往返测试。
- `docs/data-module.md`：数据约定和已知限制。
- `docs/validation-module-01.txt`：本模块实际验证输出。

## 评分规则

默认五个维度为数字正确性、引用与证据、数据时效性、安全合规、回答质量；权重依次为 30%、20%、15%、20%、15%。维度分数为 0～10 的整数，通过数组保存。

规划中的总分为 `Σ(分数 / 10 × 权重) × 100`，只统计当前有效回答且完成当前维度评分的记录。此模块仅校验数据，尚不计算排名。

## 提交状态

内置题目、证据和模型回答均为模拟，不代表问财、豆包、千问、元宝的真实表现。正式人工评审初始为空。测试夹具中的评分只用于测试。

当前测试已覆盖评审保存恢复和修改，GOAL.md 要求的汇总统计测试仍待统计模块实现。已在浏览器验证回答保存、刷新恢复、版本历史及软删除；人工评分表单已在浏览器验证部分保存、完成校验和修改历史。完整 Agent 对话导出、最终人工评分及程序生成报告也尚未交付。

## 可选模型 API

已支持 Base URL、API Key、Model Name 配置和真实 HTTP 调用入口，见 [配置说明](docs/model-api.md)。默认模拟评测仍可离线运行；只有点击“发送请求”才访问供应商。密钥仅保存在本地服务内存中。生产本地运行使用 `npm run build` 后执行 `npm start`，静态 preview 不提供 API。

## 人工评审

点击模型卡片上的“开始评审 / 编辑评审”，按动态维度打分、勾选失败标签、填写评语并保存。评分为 0～10 的整数，完成前需填齐全部启用维度。详见 [模块说明](docs/review-module.md) 和 [评分规则](docs/scoring-rules.md)。
